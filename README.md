Beating the Clock
====
A Predictive Approach to First Responder Response Time
---

Purpose:
-
The purpose of this project is to create a predictive model that would be able to predict arrivial time using controlable variables. Controlable variables would be things like dispatch answering times or agency assignments. Uncontrolable variables, like average travel time, were highly influential in predicting repsonse times, however, those variables are not able to be optimized by distpatch and first responder employees. From this created model, the most important characteristics for predicting arrival time were found with the goal of sharing this information with first repsonders to help optimize arrival time to emergencies. 

Technology Requirements:
-
This model was built using RStudio. The Quarto document used is included in this repository.
